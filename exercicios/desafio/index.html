    • Tags em HTML

    As tags em HTML são elementos que definem a estrutura e o conteúdo de uma página web. Elas são usadas para criar títulos, parágrafos, listas, links, imagens e muito mais. Cada tag tem uma função específica e pode ser combinada com outras para criar páginas web complexas e interativas.

    1. <h1> a <h6> - Títulos
    2. <p> - Parágrafos
    3. <ul> e <ol> - Listas
    4. <a> - Links
    5. <img> - Imagens
